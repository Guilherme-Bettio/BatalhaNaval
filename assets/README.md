# Assets do Batalha Naval

Este diretório pode armazenar imagens, ícones ou sprites para as versões temáticas do Batalha Naval.

Dicas:
- use PNG ou SVG para navios e explosões
- localize os assets em `assets/` e carregue-os no código com `tkinter.PhotoImage`
- mantenha o tamanho dos ícones em torno de 32x32 para usar em botões de grade

Imagens atuais usadas pela GUI:
- `assets/images/water.png`
- `assets/images/federation.png`
- `assets/images/klingon.png`
- `assets/images/hit.png`
- `assets/images/miss.png`
