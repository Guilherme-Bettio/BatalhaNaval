# Batalha Naval - Tema Star Trek

Esta pasta contém a versão original do `batalhaNaval.py` e uma versão temática em terminal e GUI inspirada em Star Trek.

## Arquivos

- `batalhaNaval.py`: versão original do jogo em terminal.
- `batalhaNaval_star_trek.py`: versão temática Star Trek em terminal com cores e mensagens.
- `batalhaNaval_star_trek_gui.py`: versão temática Star Trek com interface gráfica usando `tkinter`.

## Como executar

Terminal:

```bash
python batalhaNaval_star_trek.py
```

GUI:

```bash
python batalhaNaval_star_trek_gui.py
```

> A versão de terminal e a GUI possuem efeitos sonoros básicos. No Windows, eles usam `winsound` para tocar tons de acerto e erro.
